# イカ墨ノベル

ブラウザで使える、無料の小説アプリです。
インストール不要。スマホでもPCでも、開くだけで使えます。
読む・書く・公開する、が全部ここでできます。

**▶ アプリを開く：https://ikazu23.github.io/novel-reader/**

---

## できること

### 読む
- **名作をすぐ読める**　夏目漱石・太宰治・宮沢賢治など、青空文庫の名作をルビ付きで読めます
- **みんなの作品をさがす**　ランキング・新着・ジャンル・タグから、投稿された作品をさがして本棚に追加できます
- **続きを読む**　本棚のいちばん上から、最後に読んだ話の続きをすぐ開けます
- **読み上げ**　端末の声から好きなものを選べます。次の話も続けて再生できます
- **本ごとの見た目設定**　フォント・文字サイズ・行間・段落の間隔・背景・テーマを本ごとに保存
- **夜間テーマ**　暗い画面でも黒い文字だけ明るくして読みやすく
- **フォントの追加**　好きなフォントを入れて、全部の本で使えます
- **集中して読む**　画面のまんなかをタップすると、上のバーを隠せます
- **PCでも快適**　画面の左右の端をクリック、または ← → キーでページ送り

### 書く・公開する
- **小説を書く**　話ごとに整理して書けます。挿絵・ふりがな・置換ルールも使えます
- **作品を公開**　書いた作品を公開すると、みんなの作品一覧やランキングに載ります。本文はあなた自身のGoogleドライブに置かれます
- **ペンネームと作者ページ**　作者名とひとことを登録できます
- **下書き**　公開中の作品でも、話ごとに下書きにして非公開にできます
- **二次創作も**　「二次創作です」にチェックして原作名を書けば公開できます（ルールは利用規約を見てね）

### 取り込む
- **テキストファイルから**　.txt や .zip を新しい本として取り込めます（青空文庫のファイルもそのまま読めます）
- **話の追加**　テキスト・ZIP・訳したページ（.html）から、本に話を追加できます

※ 取り込んだ作品は、自分で読むためだけに使ってください。公開はできません。

### 韓国語の小説も
- **韓国語メモ**　韓国語の本では、単語をタップして意味を調べたり、単語帳に登録したりできます
- **復習**　単語帳のカード・穴埋めクイズ（本の中の文で出題）・苦手な単語の練習・この話の聞き流し

## はじめかた

1. 上のリンクを開く
2. 右下の「＋」から、名作を読む・新しい本を書く・ファイルから取り込む、を選ぶ
3. ほかの人の作品は、本棚の右上の「作品をさがす」から

### アプリのように使う（ホーム画面に追加）

- **Android（Chrome）**：右上の「⋮」→「ホーム画面に追加」
- **iPhone（Safari）**：下の共有ボタン →「ホーム画面に追加」

ホーム画面から開くと、ブラウザのバーが消えて普通のアプリのように使えます。

## データについて

- 本のデータは、基本的に**あなたの端末の中だけ**に保存されます
- Googleドライブ同期を使うと、**あなた自身のGoogleドライブ**の、このアプリ専用の場所に保存されます。作者を含め、ほかの人が見ることはできません
- 作品を公開したときだけ、その作品のファイルがあなたのGoogleドライブの「イカ墨ノベル 公開作品」フォルダに、リンクを知っている人が読める形で置かれます
- 端末を変える前や、ブラウザのデータを消す前には、メニューの「バックアップ」かGoogleドライブ同期で保存しておいてください
- くわしくは **[利用規約・プライバシー](https://ikazu23.github.io/novel-reader/terms.html)** を見てください

## 名作（青空文庫）について

「名作を読む」の作品は、[青空文庫](https://www.aozora.gr.jp/)で公開されている、著作権の保護期間が終わった作品です。青空文庫のボランティアの方々が入力・校正したテキストを使わせていただいています。各作品の最後に、底本と入力・校正した方の情報を載せています。
